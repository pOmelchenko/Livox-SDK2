# Fixture

- **Canonical term:** Fixture
- **Slug:** `fixture`
- **Aliases:** test fixture
- **Russian:** тестовый образец

## Definition

A fixture is fixed input data used to make a validation or test scenario repeatable.

## Repository meaning and boundaries

Documentation-validator fixtures contain small glossary trees that produce an expected pass or failure without network access.

## Example

A fixture with one indexed term and one valid term page should pass.
