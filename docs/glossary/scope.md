# Scope

- **Canonical term:** Scope
- **Slug:** `scope`
- **Aliases:** change scope
- **Russian:** объём изменений

## Definition

Scope is the explicit set of behavior, files, and outcomes a qualified change is allowed to address.

## Repository meaning and boundaries

The governing issue defines scope before implementation, and each commit stays within one independently reviewable concern.

## Example

Issue #13 includes documentation and validation but excludes SDK runtime changes.
