# Merge

- **Canonical term:** Merge
- **Slug:** `merge`
- **Aliases:** merge commit
- **Russian:** слияние

## Definition

A merge is the operation that combines histories and, in this repository's accepted pull-request flow, creates a GitHub merge commit.

## Repository meaning and boundaries

Topic branches contain no merge commits; GitHub creates the administrative merge only after current-head review and resolved discussions.

## Example

An accepted pull request adds its validated commits to `master` under one merge commit.
