# Sample application

- **Canonical term:** Sample application
- **Slug:** `sample-application`
- **Aliases:** sample; example application
- **Russian:** пример приложения

## Definition

A sample application is a small executable demonstrating one SDK integration path without becoming part of the public compatibility contract.

## Repository meaning and boundaries

Programs under `samples/` show initialization, callbacks, logging, time sync, configuration, and upgrade flows for the current revision.

## Example

`livox_lidar_quick_start` demonstrates initialization and data callbacks.
