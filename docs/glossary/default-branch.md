# Default branch

- **Canonical term:** Default branch
- **Slug:** `default-branch`
- **Aliases:** primary branch
- **Russian:** ветка по умолчанию

## Definition

The default branch is the repository branch GitHub selects as the primary integration target when no other branch is specified.

## Repository meaning and boundaries

`master` is this repository's default branch and accepted topic work reaches it through pull requests.

## Example

A new issue intake comment records the event's default-branch commit SHA.
