# Upstream

- **Canonical term:** Upstream
- **Slug:** `upstream`
- **Aliases:** canonical upstream
- **Russian:** исходный проект

## Definition

An upstream is the source project from which a downstream receives inherited code and authoritative changes.

## Repository meaning and boundaries

`Livox-SDK/Livox-SDK2` is the canonical upstream for source history, product releases, and protocol authority recorded by this downstream.

## Example

A general SDK fix may be proposed upstream while fork-specific governance remains downstream-only.
