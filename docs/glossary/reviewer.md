# Reviewer

- **Canonical term:** Reviewer
- **Slug:** `reviewer`
- **Aliases:** code reviewer
- **Russian:** рецензент

## Definition

A reviewer is a person or designated review agent that evaluates a proposed change and records findings for maintainer disposition.

## Repository meaning and boundaries

A reviewer checks the current head, evidence, compatibility, provenance, and unresolved discussions but does not replace maintainer accountability.

## Example

Codex reviews the final pull-request head and identifies an untested broken-link case.
