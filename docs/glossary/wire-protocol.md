# Wire protocol

- **Canonical term:** Wire protocol
- **Slug:** `wire-protocol`
- **Aliases:** communication protocol; on-wire protocol
- **Russian:** протокол обмена

## Definition

A wire protocol is the byte-level message format and exchange rules used by systems communicating over a network.

## Repository meaning and boundaries

Official Livox documentation remains authoritative for device communication; this downstream implements protocol handling but does not define new packet semantics.

## Example

A control-command frame and its response follow the official device protocol.
