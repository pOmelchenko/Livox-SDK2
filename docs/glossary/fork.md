# Fork

- **Canonical term:** Fork
- **Slug:** `fork`
- **Aliases:** repository fork
- **Russian:** форк

## Definition

A fork is a repository created from another repository so its history and changes can be maintained independently.

## Repository meaning and boundaries

This repository is both a GitHub fork and a maintained downstream, but those roles are not synonymous: the downstream role includes qualification and lifecycle policy.

## Example

The downstream can retain a fix after the official repository moves forward.
