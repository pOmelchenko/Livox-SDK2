# Configuration

- **Canonical term:** Configuration
- **Slug:** `configuration`
- **Aliases:** config; configuration file
- **Russian:** конфигурация

## Definition

Configuration is the external data that selects SDK network, device, role, and logger settings without recompiling the application.

## Repository meaning and boundaries

The SDK reads reviewed JSON files whose accepted fields are implemented in the current source and illustrated by sample files.

## Example

A Mid-360 sample file selects host and device ports for an isolated test network.
