# LiDAR

- **Canonical term:** LiDAR
- **Slug:** `lidar`
- **Aliases:** lidar; light detection and ranging
- **Russian:** лидар

## Definition

LiDAR is a sensing technology that measures reflected light to produce distance observations of the surrounding environment.

## Repository meaning and boundaries

In this repository LiDAR refers to supported Livox devices accessed through the SDK; product behavior remains under official Livox authority.

## Example

A Mid-360 device sends measurements that the SDK delivers as point-cloud data.
