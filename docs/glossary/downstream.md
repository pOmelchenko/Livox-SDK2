# Downstream

- **Canonical term:** Downstream
- **Slug:** `downstream`
- **Aliases:** maintained downstream
- **Russian:** сопровождаемая производная версия

## Definition

A downstream is a repository that starts from another project's source and maintains additional changes for its own qualified needs.

## Repository meaning and boundaries

This repository preserves Livox attribution and protocol authority while carrying auditable fixes and governance beyond its recorded upstream base.

## Example

`pOmelchenko/Livox-SDK2` is downstream of `Livox-SDK/Livox-SDK2`.
