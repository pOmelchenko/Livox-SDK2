# Negative fixture

- **Canonical term:** Negative fixture
- **Slug:** `negative-fixture`
- **Aliases:** invalid fixture
- **Russian:** отрицательный тестовый образец

## Definition

A negative fixture is fixed input intentionally violating one contract so a validator's rejection behavior can be proved.

## Repository meaning and boundaries

Each documentation negative fixture isolates a duplicate, omission, or broken-link condition and must fail for the expected reason.

## Example

A term page containing two `## Definition` headings is a negative fixture.
