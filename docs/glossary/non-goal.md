# Non-goal

- **Canonical term:** Non-goal
- **Slug:** `non-goal`
- **Aliases:** out of scope
- **Russian:** нецель

## Definition

A non-goal is an outcome explicitly excluded from a qualified change so review does not infer broader intent.

## Repository meaning and boundaries

Issue qualification records non-goals before implementation and changes that exceed them require new direction or a separate issue.

## Example

Changing SDK runtime behavior is a non-goal of issue #13.
