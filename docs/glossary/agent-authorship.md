# Agent authorship

- **Canonical term:** Agent authorship
- **Slug:** `agent-authorship`
- **Aliases:** agent participation; agent disclosure
- **Russian:** авторство агента

## Definition

Agent authorship is the recorded degree to which an automated agent created or influenced a repository change.

## Repository meaning and boundaries

This repository records agent participation in every topic commit and repeats it in the pull-request description without inventing a human co-author.

## Example

A commit substantially written by Codex ends with `Agent-Authored: OpenAI Codex`.
