# Pull request

- **Canonical term:** Pull request
- **Slug:** `pull-request`
- **Aliases:** PR; merge request
- **Russian:** запрос на включение изменений

## Definition

A pull request is the GitHub review record proposing that one branch be merged into another.

## Repository meaning and boundaries

Downstream work starts as a draft pull request, undergoes automated checks and human review, and merges only after current-head verification and resolved discussions.

## Example

A topic branch for issue #13 opens a draft pull request into `master`.
