# Status check

- **Canonical term:** Status check
- **Slug:** `status-check`
- **Aliases:** commit status; check run
- **Russian:** проверка статуса

## Definition

A status check is a named result attached to a commit that reports the outcome of an automated or external evaluation.

## Repository meaning and boundaries

Checks provide bounded evidence; their names, source, exact revision, and limitations determine what reviewers may infer.

## Example

`Downstream governance: success` reports that the immutable commit contract passed.
