# Branch

- **Canonical term:** Branch
- **Slug:** `branch`
- **Aliases:** Git branch
- **Russian:** ветка

## Definition

A branch is a movable repository name that points to the latest commit in one line of work.

## Repository meaning and boundaries

Topic branches hold unmerged work; consumers do not treat a mutable branch name as a release identity.

## Example

`agent/issue-13-versioned-sdk-docs` points to the current documentation work.
