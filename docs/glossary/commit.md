# Commit

- **Canonical term:** Commit
- **Slug:** `commit`
- **Aliases:** Git commit; revision
- **Russian:** коммит

## Definition

A commit is an immutable repository object that records one tree, its parent history, authorship metadata, and a message.

## Repository meaning and boundaries

Each downstream topic commit contains one reviewable concern and follows the exact message contract once published.

## Example

Commit `20471ce` records the upstream drift query trust boundary.
