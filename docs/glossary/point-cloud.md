# Point cloud

- **Canonical term:** Point cloud
- **Slug:** `point-cloud`
- **Aliases:** point-cloud data
- **Russian:** облако точек

## Definition

A point cloud is a collection of spatial samples representing measured points in an environment.

## Repository meaning and boundaries

The SDK delivers Livox point-cloud packets and coordinate formats through public callbacks; official documentation defines device-specific meaning.

## Example

The quick-start sample prints metadata from point-cloud packets received from a connected device.
