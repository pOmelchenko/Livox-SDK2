# Compatibility

- **Canonical term:** Compatibility
- **Slug:** `compatibility`
- **Aliases:** compatibility boundary
- **Russian:** совместимость

## Definition

Compatibility is the degree to which an existing integration continues to work after a change without an unplanned migration.

## Repository meaning and boundaries

Downstream review considers API, ABI, wire, platform, packaging, device, and consumer effects separately and requires evidence matching each claimed boundary.

## Example

A documentation-only change can preserve runtime compatibility while still changing contributor workflow.
