# Commit SHA

- **Canonical term:** Commit SHA
- **Slug:** `commit-sha`
- **Aliases:** commit ID; object ID
- **Russian:** SHA коммита

## Definition

A commit SHA is the hexadecimal object identifier that names one exact Git commit.

## Repository meaning and boundaries

Full commit SHAs identify bases, evidence, releases, and rollback targets; short forms are only display conveniences when unambiguous.

## Example

`e3fd6540ee8598968cbaf00e0b415726124371dc` identifies the qualified base for issue #13.
