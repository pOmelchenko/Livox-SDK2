# Tag

- **Canonical term:** Tag
- **Slug:** `tag`
- **Aliases:** Git tag; annotated tag
- **Russian:** тег

## Definition

A tag is a Git reference intended to give a stable name to one repository object, often a release commit.

## Repository meaning and boundaries

Published downstream release tags are annotated, qualified, and never moved or reused; a tag name alone does not prove support.

## Example

`downstream-v1.4.3-r1` names one exact qualified release commit when validly published.
