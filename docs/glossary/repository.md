# Repository

- **Canonical term:** Repository
- **Slug:** `repository`
- **Aliases:** repo; Git repository
- **Russian:** репозиторий

## Definition

A repository is the versioned collection of files, commits, references, and metadata maintained as one project history.

## Repository meaning and boundaries

This repository contains upstream-derived SDK source plus auditable downstream changes and canonical documentation.

## Example

The `docs/` tree and SDK source are reviewed in the same repository history.
