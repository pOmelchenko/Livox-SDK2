# CI

- **Canonical term:** CI
- **Slug:** `ci`
- **Aliases:** continuous integration
- **Russian:** непрерывная интеграция

## Definition

CI is automated execution of repeatable checks in response to repository events.

## Repository meaning and boundaries

GitHub Actions runs build, regression, governance, and documentation checks, while review remains responsible for interpreting their scope.

## Example

A pull request triggers a Linux build and the documentation validator.
