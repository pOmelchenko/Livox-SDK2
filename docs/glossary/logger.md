# Logger

- **Canonical term:** Logger
- **Slug:** `logger`
- **Aliases:** logging subsystem
- **Russian:** подсистема журналирования

## Definition

A logger is the SDK facility that receives or records diagnostic data for later inspection.

## Repository meaning and boundaries

This repository distinguishes SDK console logging, device log reception, configured storage limits, and application responsibility for secure retention.

## Example

`lidar_log_path` selects where configured device log data is stored.
