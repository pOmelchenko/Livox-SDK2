# Positive fixture

- **Canonical term:** Positive fixture
- **Slug:** `positive-fixture`
- **Aliases:** valid fixture
- **Russian:** положительный тестовый образец

## Definition

A positive fixture is fixed input satisfying the contract so a validator's acceptance behavior can be proved.

## Repository meaning and boundaries

The documentation test suite keeps a minimal valid glossary that must pass before negative cases are evaluated.

## Example

A correctly indexed term page with one definition is a positive fixture.
