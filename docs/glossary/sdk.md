# SDK

- **Canonical term:** SDK
- **Slug:** `sdk`
- **Aliases:** software development kit; Livox SDK2
- **Russian:** комплект средств разработки

## Definition

An SDK is a set of libraries, public interfaces, examples, and supporting material used to build applications for a platform or device.

## Repository meaning and boundaries

In this repository SDK refers to Livox SDK2 source, installed headers, libraries, and samples; downstream policy and documentation govern but do not redefine Livox devices.

## Example

An application links `livox_lidar_sdk_static` and includes `livox_lidar_api.h`.
