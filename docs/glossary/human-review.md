# Human review

- **Canonical term:** Human review
- **Slug:** `human-review`
- **Aliases:** manual review
- **Russian:** человеческая проверка

## Definition

Human review is accountable evaluation by a person of a change's correctness, evidence, risk, and disposition.

## Repository meaning and boundaries

Automated checks support but do not replace review; the maintainer resolves discussions only after verifying the concern is addressed.

## Example

A reviewer checks whether a passing test actually covers the claimed callback lifetime.
