# Workflow

- **Canonical term:** Workflow
- **Slug:** `workflow`
- **Aliases:** GitHub Actions workflow; automation workflow
- **Russian:** рабочий процесс автоматизации

## Definition

A workflow is a versioned automation definition that runs one or more jobs in response to selected events.

## Repository meaning and boundaries

Files under `.github/workflows/` define bounded CI and governance tasks with explicit permissions and inputs.

## Example

The documentation workflow runs the validator and its unit tests on a pull request.
