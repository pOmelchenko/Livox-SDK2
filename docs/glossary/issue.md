# Issue

- **Canonical term:** Issue
- **Slug:** `issue`
- **Aliases:** GitHub issue
- **Russian:** задача

## Definition

An issue is the repository record that qualifies one problem or inseparable maintenance concern before implementation.

## Repository meaning and boundaries

The issue stores reporter evidence and maintainer decisions about scope, provenance, compatibility, verification, agent participation, and upstream disposition.

## Example

Issue #13 governs the versioned documentation and glossary work.
